# Sumanth Golla - Portfolio

Static site for GitHub Pages. No build step.

Files: index.html, style.css, script.js, 404.html, assets/ (put Sumanth_Golla_Resume.pdf here), .nojekyll

## Deploy with a custom domain
1. Upload ALL files to the ROOT of your sumanth8022.github.io repo. Keep assets/Sumanth_Golla_Resume.pdf.
2. Rename CNAME.example to CNAME and make sure it holds your real domain on one line (www.sumanthportfolio.com or www.sumanthportfolio.in).
3. Settings > Pages > Custom domain > enter the same domain > Save. Tick "Enforce HTTPS" when available.
4. At your registrar add: CNAME  www -> sumanth8022.github.io
   For the bare domain also add A records @ -> 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
